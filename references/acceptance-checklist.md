# 交付前验收清单

完成排版后，必须逐项验收。只有全部适用项目通过，才可声明成品符合本校论文格式规范。不得跳过、简化、降级或以部分核验替代任一适用项目。原文缺失或无法可靠判定的信息不得臆测补齐；须说明为“待用户确认”，并停止交付，直至获得判断或完成核验。

## 1. 内容保真

- [ ] 正文、标题、摘要、关键词、直接引文、脚注、图表题注和参考文献条目的文字逐字未变。
- [ ] 没有润色、改写、扩写、缩写、纠错、替换词语、补全信息或调整句序、逻辑。
- [ ] 唯一字符级改动仅为已授权的等价中文标点统一：符号的语义、位置和数量未改变。

## 2. 页面与章节结构

- [ ] 页边距为上 3 cm、下 2 cm、左 3 cm、右 3 cm。
- [ ] 封面、摘要、目录及前言前置页无页码；正文首页开始使用阿拉伯页码，底端居中。
- [ ] 每个一级标题均新开一页；二级标题未因本规则被强制分页。
- [ ] 每个一级标题居中，且为宋体 18 号加粗。
- [ ] 无意外空白页；无因删除多余空行造成的内容段落缺失。

## 3. 字体、字号与段落

- [ ] 中文正文为宋体 12 号，英文和数字正文为 Calibri 12 号。
- [ ] 中文引文为楷体 12 号；英文引文为斜体 Calibri 12 号。
- [ ] 一级、二级、三级标题分别为宋体 18、16、14 号并加粗。
- [ ] 中文全文为 1.5 倍行距，段落间无空行。
- [ ] 图表正文、图表标题和脚注均使用规定的 10 号样式。

## 4. 摘要、目录与标题

- [ ] 摘要页的题目、摘要标签、摘要正文和关键词格式符合规范，摘要后仅保留规定的一行间隔。
- [ ] 目录从摘要后新页开始；“目录”居中、宋体 24 号。
- [ ] 目录完整收录现有一、二、三级标题；左侧标题、点引导符、右侧 Calibri 页码和两端对齐正确。
- [ ] 标题层级与原有文字相符：一级为“一、xxx”，二级为“（一）、xxx”；未改写标题文字。

## 5. 标点、脚注与引文

- [ ] 中文语境中所有双引号均为中文“”，未遗留英文半角 `""`。
- [ ] 中文语境中其他标点均为中文全角形式；没有改变任何标点的数量、位置或含义。
- [ ] 纯英文引文、英文书目信息、代码、URL、邮箱及数学/技术表达式的原有标点未被误转换。
- [ ] 直接引文的引号、字体和长引文缩进符合规范。
- [ ] 脚注为页下注、宋体 10 号和带圈数字标号；标号位置符合整句、短语和大段引文规则。
- [ ] 正文右上角脚注标记及页下注开头标号均为宋体带圈数字；脚注日期中的“月”字已删除。
- [ ] 缺失的首次引注出版信息、古代年号公元纪年或英文原名没有被擅自补写。

## 6. 图表与参考文献

- [ ] 图表位于首次提及附近，非必要未分页；表题在表上、图题在图下，居中 10 号加粗。
- [ ] 图与表分别连续编号，题注为既有文字的“图 X：标题”“表 X：标题”格式。
- [ ] 参考文献另起新页，标题居中、宋体 14 号加粗。
- [ ] 参考文献保留已有序号、两端对齐，并按规定的中文/英文、分类及排序规则整理。
- [ ] 参考文献序号从 1 起连续递增，无重复、跳号或错序；分类标题前无空格或首行缩进。
- [ ] 每两个参考文献分类之间恰空一行；分类标题的字体、字号、对齐、缩进和段前段后已获用户明确并逐项符合。
- [ ] 未为实现排序而改动任一参考文献条目的文字。

## 7. 交付结论

- [ ] 已渲染最终文件并逐页检查；无裁切、重叠、意外空白页、页眉页脚错位、错误分页或目录/页码未更新。
- [ ] 已复核无残留乱格式、重复换行、未更新目录或错误页码。
- [ ] 所有适用项目均通过；若有未通过项、待确认项或无法验证项，已停止交付，未将文件称为完成版或合规版。
