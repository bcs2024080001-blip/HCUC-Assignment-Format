# thesis-formatting-only

严格按照指定学校的中文学术论文格式规范，对 Word 论文进行**纯排版、纯格式化处理**。

本 Skill 的核心原则是：

> **只改格式，不改内容。**

适用于用户明确要求“只排版、不改写”“按学校论文格式规范调整 Word 文档”等场景。不用于论文润色、校对、改写、补写、内容编辑或学术观点修改。

---

## 1. 适用场景

当用户提出以下类型的需求时使用：

* 按学校论文格式规范整理 Word 文档
* 调整论文页面、字体、字号、行距、缩进等格式
* 统一论文标题层级和样式
* 调整摘要、目录、正文、参考文献等版式
* 规范脚注、直接引文、图表题注及编号
* 清理多余空行、重复换行和混乱格式
* 更新已有目录及目录页码
* 对论文进行最终格式验收

如果用户要求**润色、改写、校对、纠错、扩写、缩写、调整论证逻辑或修改论文内容**，不得使用本 Skill 完成这些操作。

---

## 2. 核心职责

本 Skill 仅负责以下工作：

* 页面设置
* 字体、字号和字符样式
* 段落格式
* 首行缩进、对齐方式
* 行距、段前段后间距
* 标题层级及标题样式
* 分页与分页控制
* 页眉、页脚及页码
* 目录生成与更新
* 脚注格式
* 直接引文及长引文格式
* 图表位置、题注及编号
* 参考文献排版及序号格式
* 多余空行、重复换行及明显格式混乱的清理
* 最终 Word 文档的结构检查与页面渲染核验

所有操作都必须以**不改变正文内容**为前提。

---

## 3. 严格禁止修改的内容

除明确允许的格式性例外外，不得：

* 修改正文文字
* 修改标题文字
* 修改摘要内容
* 修改关键词内容
* 修改观点或论证
* 调整语序
* 改写句子
* 增删正文内容
* 修改直接引文内容
* 修改引文原意
* 修改脚注正文
* 修改参考文献条目文字
* 补充缺失的作者、年份、出版社、页码等信息
* 擅自更改繁体字、古籍文字或专有人名
* 擅自删除或增加有实际文字内容的段落
* 根据个人判断“优化”论文内容

不得因为内容存在错别字、语病、格式疑似错误或信息缺失而擅自修改内容。

---

### 4.1 中文标点统一
